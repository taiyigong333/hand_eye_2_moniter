# 快速上手

这份文档只保留最短可执行路径。详细说明见 `README.md` 和 `docs/1_使用说明.md`，标定前参数确认见 `docs/11_标定前参数确认清单.md`。

## 1. 准备环境

在项目根目录执行：

```powershell
conda env update -n hand_eye -f environment.yml
conda activate hand_eye
```

当前机器也可以直接使用：

```powershell
F:\Anaconda\Anaconda3\envs\hand_eye\python.exe
```

## 2. 先用已有数据验证标定

需要本地存在 `data/dataset_from_npz/`；该目录已被忽略，不随 Git 保存。

运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_current_calibration.ps1
```

如果只需要末端腕部相机的眼在手上结果，不依赖固定相机图像：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_eye_in_hand_calibration.ps1
```

双相机脚本默认输出到：

```text
outputs/calib_output_correct_intr/
```

眼在手上脚本默认输出到：

```text
outputs/eye_in_hand_calibration/
```

会生成：

```text
outputs/calib_output_correct_intr/
├── calibration_result.json          # 最终标定结果
├── dynamic_end_camera_poses.json    # 每个有效样本的末端相机动态位姿
└── debug_vis/                       # ArUco 检测点和重投影调试图
```

最重要的结果在 `calibration_result.json`：

- `T_ee_cam_end`：末端相机到机械臂末端坐标系的外参。
- `T_base_board`：标定板到机器人基座坐标系的外参。
- `T_base_cam_fixed`：固定相机到机器人基座坐标系的外参，仅双相机联合模式输出。

## 3. 实时采集前检查配置

先打开并确认：

```text
configs/live_collection.example.json
```

完整参数清单见 `docs/11_标定前参数确认清单.md`。

重点检查：

- `robot.host`：UR7e IP。
- `robot.program`：示教器中的 URP 程序名，当前示例配置为 `autoHandEye2.urp`。
- `robot.pause_before_capture` / `robot.capture_settle_s`：拍照前暂停示教器程序，并等待 0.5 秒再采图。
- `robot.stop_after_collection`：采集结束后发送 Dashboard `stop`，停止示教器程序。
- `cameras[].serial`：当前模式所需 RealSense 的序列号。
- `preview.enabled`：默认打开两路 RGB 预览窗口。
- `sampling.mode`：`timed` 定时采集，或 `manual` 手动采集。
- `sampling.interval_s` / `sampling.max_samples`：定时采样间隔和数量。
- `calibration.mode`：`dual_camera` 默认双相机联合标定；`eye_in_hand` 只启动末端相机并只跑眼在手上。
- `calibration.output_dir`：自动标定结果输出目录；默认 `outputs/live_calibration` 会在运行时自动追加时间戳。
- `live_calibration` 输出文件和 JSON 字段含义见 `docs/5_实时标定输出字段说明.md`。

先 dry-run，不连接机器人和相机：

```powershell
F:\Anaconda\Anaconda3\envs\hand_eye\python.exe scripts\collect_and_calibrate.py --dry_run
```

## 4. 实时定时采集并自动标定

确认 UR7e、RTDE、Dashboard 和 RealSense 都可用后运行：

```powershell
F:\Anaconda\Anaconda3\envs\hand_eye\python.exe scripts\collect_and_calibrate.py `
  --config configs\live_collection.example.json
```

如果本轮只做眼在手上标定：

```powershell
F:\Anaconda\Anaconda3\envs\hand_eye\python.exe scripts\collect_and_calibrate.py `
  --config configs\live_collection.example.json `
  --calibration_mode eye_in_hand
```

默认流程：

1. PC 通过 Dashboard 加载并启动配置文件中的 URP 程序。
2. UR7e 围绕标定板运动。
3. PC 通过 RTDE 读取 TCP。
4. PC 读取当前标定模式所需的 RealSense RGB 图像，并打开预览窗口；`eye_in_hand` 只启动末端相机。
5. 每次采样前发送 Dashboard `pause`，等待 `robot.capture_settle_s` 后拍照，拍照完成后发送 `play`。
6. 样本数达到 `sampling.max_samples` 后发送 Dashboard `stop` 停止示教器程序，再自动调用 `calib.py`。

## 5. 手动采集

如果要人工控制采样时机：

```powershell
F:\Anaconda\Anaconda3\envs\hand_eye\python.exe scripts\collect_and_calibrate.py `
  --config configs\live_collection.example.json `
  --mode manual
```

默认按键：

- `c`：保存一次样本。
- `q`：结束采集并进入自动标定。

Windows 下是单键读取，不需要回车。默认也可以在预览窗口聚焦时按 `c` / `q`；定时模式下按 `q` 可提前结束采集。

## 6. 实时采集输出

样本默认输出到：

```text
data/live_capture/
```

结构：

```text
data/live_capture/
├── capture_session_config.json      # 本次采集配置快照
├── sample_000/
│   ├── cam0_wrist.png               # 末端相机 RGB 图像
│   ├── cam1_main.png                # 固定相机 RGB 图像
│   └── pose.json                    # TCP、关节角、图像元数据
├── sample_001/
│   └── ...
└── ...
```

若 `enable_depth=true`，样本目录还会包含深度图：

```text
depth0_wrist.png
depth1_main.png
```

深度图按 RealSense 原始 `z16` 保存，真实深度为：

```text
depth_m = raw_value * depth_scale_m
```

自动标定结果默认输出到：

```text
outputs/live_calibration_YYYYMMDD_HHMMSS/
├── calibration_result.json
├── dynamic_end_camera_poses.json
└── debug_vis/
```

结果文件和各 JSON 字段含义见 `docs/5_实时标定输出字段说明.md`。

## 8. 实机最小检查

- PC 能 ping 通 `robot.host`。
- UR 控制柜已启用 Dashboard server 和 RTDE。
- `configs/live_collection.example.json` 中的 `robot.program` 已在示教器中。
- 如启用 `robot.pause_before_capture`，示教器程序能被 Dashboard `pause` 暂停，并能用 `play` 继续。
- 当前模式需要的 RealSense 没有被 RealSense Viewer 占用。
- `dual_camera` 模式下两台相机都能看到标定板；`eye_in_hand` 模式下至少末端腕部相机能看到标定板。
- `--dry_run` 打印出的 `calib.py` 参数符合预期。
