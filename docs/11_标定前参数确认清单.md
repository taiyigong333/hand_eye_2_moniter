# 标定前参数确认清单

这份文档用于在开始手眼标定前，把必须确定的参数一次性确认清楚。目标很简单：先把机器人、相机、标定板、采样和输出路径对齐，再开始采集，避免后面因为序列号、板尺寸或程序名不一致返工。

## 1. 先确认什么

### 1.1 标定模式

- `eye_in_hand`：只跑眼在手上，末端相机随机械臂运动，目标结果是 `T_ee_cam_end`。
- `dual_camera`：默认双相机联合流程，先求 `T_ee_cam_end`，再基于同一块固定标定板估计 `T_base_cam_fixed`。
- 只用固定相机独立求 `T_base_cam_fixed` 的 eye-to-hand / robot-world-hand-eye 分支当前仍未实现。

### 1.2 坐标系约定

- 当前代码统一使用 `T_A_B`，含义是把 `B` 坐标系下的点变换到 `A` 坐标系。
- `calib.py` 和后续文档都默认这个约定，不要把“从 A 到 B”和“从 B 到 A”混着填。

## 2. 机器人侧必须确定的参数

| 参数 | 需要确认的内容 | 对应配置 |
| --- | --- | --- |
| 控制柜 IP | PC 是否能连到 UR 控制柜 | `robot.host` |
| Dashboard 端口 | 一般为 `29999`，不要和实际控制柜配置冲突 | `robot.dashboard_port` |
| URP 程序名 | 示教器里已经保存的程序名 | `robot.program` |
| 自动加载/播放 | 是否由 PC 自动 `load`、`play` | `robot.load_program`、`robot.play_after_load` |
| 停止后再加载 | 需要时是否先停机再载入程序 | `robot.stop_before_load` |
| 拍照前暂停 | 每次拍照前是否暂停示教器程序 | `robot.pause_before_capture` |
| 暂停后等待 | 发送暂停信号后等待多久再拍照 | `robot.capture_settle_s` |
| 拍照后继续 | 拍照完成后是否发送 `play` 继续程序 | `robot.resume_after_capture` |
| 采集后停止 | 采集循环结束后是否发送 `stop` 停止示教器程序 | `robot.stop_after_collection` |
| 当前末端位姿参考系 | 采集期间必须明确 RTDE 保存的是法兰盘中心还是夹爪 TCP，且不能中途切换 | 示教器当前设置；见 [15_法兰盘中心与夹爪TCP对标定的影响.md](15_法兰盘中心与夹爪TCP对标定的影响.md) |

补充说明：

- 采集时保存的末端位姿参考系必须和后续解释外参、生成抓取目标时使用的参考系一致。
- 当前实时采集默认用 Dashboard `pause/play` 做拍照同步；如果示教器程序不能被这种方式暂停并继续，先关闭 `robot.pause_before_capture` 或调整 URP。
- 当前实时采集默认在采集结束后发送 Dashboard `stop`，避免自动标定阶段示教器程序继续运行；确实不希望停止时再关闭 `robot.stop_after_collection`。
- 机械臂末端夹具、法兰、工具偏置如果变了，要重新确认整条标定链。

## 3. 相机侧必须确定的参数

| 参数 | 需要确认的内容 | 对应配置 |
| --- | --- | --- |
| 相机序列号 | 当前标定模式所需 RealSense 要能被稳定识别 | `cameras[].serial` |
| 相机角色 | 哪一台是腕部相机，哪一台是固定相机 | `cameras[].role` |
| 相机索引 | 代码里用哪个索引对应哪台相机 | `cameras[].camera_index` |
| 分辨率 | 实际启动的 profile 必须和配置一致 | `cameras[].color_width`、`cameras[].color_height` |
| 帧率 | 采集时实际 FPS | `cameras[].fps` |
| 内参文件 | 启动后写出的内参路径要和后续标定使用的文件一致 | `cameras[].intrinsics_path` |
| 深度开关 | 标定阶段通常只需要 RGB，深度是否启用要先确认 | `cameras[].enable_depth` |

补充说明：

- 当前示例里 `camera_index=0` 是腕部相机，`camera_index=1` 是外部固定相机。
- 如果开启 `refresh_intrinsics_from_device`，要确认设备当前 active profile 和内参文件匹配。

## 4. 标定板侧必须确定的参数

| 参数 | 需要确认的内容 | 对应配置 |
| --- | --- | --- |
| 布局类型 | 当前使用的标定板布局 | `calibration.board_layout` |
| 网格行列 | 角点/单元格的行列数 | `calibration.grid_rows`、`calibration.grid_cols` |
| tag 尺寸 | ArUco marker 的边长，单位是米 | `calibration.tag_size` |
| cell 尺寸 | 单元格尺寸，单位是米 | `calibration.cell_size` |
| 字典类型 | 例如 `DICT_6X6_250` | `calibration.aruco_dict` |
| 左上角约定 | 左上角是否是 tag | `calibration.top_left_is_tag` |
| ID 映射 | marker ID 到棋盘位置的映射文件 | `calibration.id_map_json` |

补充说明：

- 纸面打印、裁切和贴板后的实物尺寸必须和配置里的 `tag_size`、`cell_size` 对上。
- 如果换了板图、换了字典，`assets/boards/aruco_id_map_new.json` 也要一起重做。

## 5. 采样和过滤参数

| 参数 | 需要确认的内容 | 对应配置 |
| --- | --- | --- |
| 采样模式 | 定时采样还是手动采样 | `sampling.mode` |
| 标定模式 | 只跑眼在手上还是双相机联合标定 | `calibration.mode` |
| 采样间隔 | 定时模式下每次采样的间隔 | `sampling.interval_s` |
| 最大样本数 | 本轮最多采多少帧 | `sampling.max_samples` |
| 手动按键 | 手动模式下的抓取和结束按键 | `sampling.manual_capture_key`、`sampling.manual_stop_key` |
| 最小样本数 | 少于这个数量就不建议继续算 | `calibration.min_samples` |
| 重投影阈值 | 单样本的 RMSE 过滤阈值 | `calibration.max_reproj_rmse` |

补充说明：

- `eye_in_hand` 模式至少要保证末端腕部相机稳定看到标定板；`dual_camera` 模式要保证两台相机都能稳定看到标定板。
- 如果样本太少，或者姿态变化太单一，后面的外参会很不稳。

## 6. 数据和输出路径

| 参数 | 需要确认的内容 | 对应配置 |
| --- | --- | --- |
| 数据目录 | 采集数据最终写到哪里 | `dataset_dir`、`calibration.dataset_dir` |
| 输出目录 | 标定结果最终写到哪里 | `calibration.output_dir` |
| 是否刷新内参 | 是否在采集时重新从设备写内参文件 | `refresh_intrinsics_from_device` |
| 输入内参文件 | 当前标定模式实际使用哪份内参 | `calibration.intr_end`；`dual_camera` 模式还需要 `calibration.intr_fixed` |

补充说明：

- `output_dir` 如果保持为 `outputs/live_calibration`，运行时会自动带时间戳，避免覆盖上一轮结果。
- 如果要长期保留某轮结果，最好单独复制一份目录并记录对应配置。

## 7. 开跑前最小检查

1. `robot.host` 能连通，Dashboard 和 RTDE 都可用。
2. `robot.program` 在示教器里已经存在。
3. 若启用 `robot.pause_before_capture`，示教器程序能响应 Dashboard `pause`，并能在拍照后用 `play` 继续。
4. `calibration.mode` 已确认：`eye_in_hand` 只启动并检查末端腕部相机；`dual_camera` 检查末端腕部相机和固定相机。
5. 当前模式所需相机的序列号、分辨率、FPS 和内参路径都已确认。
6. 标定板实物尺寸、字典和 ID 映射都和配置一致。
7. `sampling.mode`、`sampling.max_samples` 和 `calibration.max_reproj_rmse` 已确定。
8. 数据目录和输出目录已经明确，不会混到别的实验里。
