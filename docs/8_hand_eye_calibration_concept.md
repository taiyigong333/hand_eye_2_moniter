# 手眼标定定义、过程与本项目采用的方法

本文是说明性文档，面向第一次阅读手眼标定流程的人。重点说明手眼标定要解决什么问题、一般怎样采集和计算，以及本项目采用的是哪一种标定思路。

## 1. 什么是手眼标定

机器人系统中通常至少有两个重要坐标系：

- 机器人坐标系：机器人控制器理解的坐标系，常见的是基座坐标系、末端坐标系和工具 TCP 坐标系。
- 相机坐标系：相机看到的三维点所在的坐标系，通常由 RGB-D 相机或工业相机给出。

手眼标定要解决的问题是：**找到相机坐标系和机器人坐标系之间的固定几何关系**。

如果没有这个关系，相机只能说“物体在相机前方多少米”，机器人却不知道这个点在自己基座坐标系下在哪里。标定完成后，系统就可以把相机中的三维点、标定板、抓取位姿或检测结果转换到机器人坐标系中，让机器人能够执行运动。

手眼标定的结果通常是一个 4x4 齐次变换矩阵，它同时包含旋转和平移：

```text
T = [ R  t ]
    [ 0  1 ]
```

其中：

- `R` 表示两个坐标系之间的姿态关系。
- `t` 表示两个坐标系原点之间的平移关系。

## 2. 眼在手上与眼在手外

手眼标定常见有两种安装方式。

### 2.1 眼在手上

眼在手上指相机安装在机械臂末端，随着末端一起运动。腕部相机、夹爪旁边的小相机都属于这类。

这种情况下，相机和机械臂末端之间的相对关系是固定的。标定目标是求：

```text
末端相机坐标系 -> 机械臂末端坐标系
```

标定完成后，只要知道机器人当前末端在基座中的位姿，就能推算出当前相机在基座中的位姿。

眼在手上的典型用途是：

- 机器人移动到不同位置拍摄目标。
- 相机跟着夹爪靠近物体。
- 需要根据当前机器人姿态实时计算相机外参。

### 2.2 眼在手外

眼在手外指相机固定在机器人外部，不随机械臂运动。例如固定在桌边、支架上或工作站上方的主相机。

这种情况下，相机和机器人基座之间的相对关系是固定的。标定目标是求：

```text
固定相机坐标系 -> 机器人基座坐标系
```

标定完成后，相机看到的点可以直接转换到机器人基座坐标系中。固定相机抓取通常使用这种结果。

眼在手外的典型用途是：

- 固定相机观察整个工作台。
- 机器人根据固定相机输出的目标点去抓取。
- 相机不随机器人运动，外参在一段时间内保持不变。

## 3. 手眼标定的一般过程

不论眼在手上还是眼在手外，标定过程都依赖两类观测：

1. 机器人位姿：机器人控制器记录的末端或 TCP 位姿。
2. 标定板位姿：相机通过标定板图像估计出的标定板相对相机的位姿。

一般流程如下。

第一步，准备标定板。标定板需要有已知几何尺寸，例如棋盘格、ArUco 板或 AprilTag 板。标定板上每个角点或 marker 的三维位置必须已知。

第二步，采集多组姿态。机器人移动到多个不同姿态，每个姿态下记录机器人位姿，并拍摄标定板图像。姿态需要有足够旋转变化，只平移或姿态变化过小会使标定结果不稳定。

第三步，相机估计标定板位姿。根据相机内参、标定板尺寸和图像中的角点位置，计算标定板相对相机的三维位姿。

第四步，建立多组几何约束。每一组机器人位姿和相机观测都提供一条约束，多组约束共同求解相机和机器人之间的固定变换。

第五步，检查结果一致性。标定结果应能让不同样本推算出的固定关系基本一致。如果不同样本之间差异很大，通常说明采集姿态、相机内参、标定板识别或坐标定义存在问题。

## 4. 眼在手上的计算思想

眼在手上时，相机固定在机器人末端。设未知量为：

```text
X = 末端相机到机械臂末端的固定变换
```

机器人每移动到一个姿态，都会得到：

- 机械臂末端在机器人基座中的位姿。
- 标定板在末端相机中的位姿。

如果标定板在环境中保持不动，那么无论机器人从哪个姿态观察它，推算出来的“标定板在机器人基座中的位姿”都应该相同。

这就形成了手眼标定的核心约束：

```text
机器人运动变化 @ X = X @ 相机观测变化
```

常见写法是：

```text
A X = X B
```

其中：

- `A` 来自机器人末端在不同采样姿态之间的相对运动。
- `B` 来自相机观察到的标定板在不同采样姿态之间的相对运动。
- `X` 是要求解的手眼关系。

求出 `X` 后，机器人就知道相机相对于末端的位置和方向。

## 5. 眼在手外的计算思想

眼在手外时，相机固定在环境中。目标是求固定相机到机器人基座的变换。

常见的独立眼在手外方法是把标定板固定在机器人末端或夹具上。机器人移动时，标定板跟着末端运动；固定相机从外部观察标定板。这样每个姿态都满足：

```text
机器人基座 -> 机械臂末端 -> 标定板
=
机器人基座 -> 固定相机 -> 标定板
```

也就是说，机器人侧和相机侧都在描述同一块标定板，只是经过的坐标链不同。通过多组姿态，可以同时约束固定相机在机器人基座中的位置，以及标定板相对末端的安装关系。

这种方法适合只有固定相机、没有末端相机的系统。

## 6. 本项目采用的方法

本项目采用的是**双相机联合标定方法**，同时使用：

- 一个安装在机械臂末端的腕部相机。
- 一个固定在机器人外部的主相机。
- 一块在采集过程中保持不动的标定板。

整体思路分两步。

第一步，先用腕部相机做眼在手上标定。机器人移动到多个姿态，腕部相机从不同角度观察同一块固定标定板。根据机器人位姿和腕部相机看到的标定板位姿，求出腕部相机到机械臂末端的固定关系。

第二步，利用腕部相机结果确定标定板在机器人基座中的位置。因为腕部相机和机器人末端的关系已经知道，所以每个样本都可以把“腕部相机看到的标定板”转换到机器人基座中。多组样本平均后，可以得到一个稳定的标定板基座位姿。

第三步，固定相机也在同一批样本中观察同一块标定板。由于标定板在机器人基座中的位姿已经确定，固定相机又能看到标定板相对自己的位姿，因此可以反推出固定相机到机器人基座的外参。

因此，本项目最终得到两类结果：

```text
腕部相机 -> 机械臂末端
固定相机 -> 机器人基座
```

其中，固定相机到机器人基座的外参用于后续固定相机引导抓取；腕部相机到机械臂末端的外参用于描述腕部相机随机器人运动时的动态位姿。

## 7. 本项目方法的特点

本项目方法不是单独只用固定相机的眼在手外标定，而是先通过腕部相机建立标定板在机器人基座中的稳定位置，再反推出固定相机外参。

这种方法有几个特点：

- 标定板在采集期间保持不动。
- 每个有效样本需要机器人位姿、腕部相机图像和固定相机图像共同成立。
- 固定相机外参会受到腕部相机手眼结果、标定板位姿估计和固定相机观测质量的共同影响。
- 如果腕部相机标定不稳定，固定相机结果也会被影响。
- 如果固定相机图像中的标定板识别不准确，固定相机外参也会偏差。

因此，本项目的固定相机外参并不是孤立计算出来的，而是建立在“腕部相机眼在手上结果 + 同一块固定标定板 + 固定相机观测”这条联合几何链路上。

## 8. 数据质量要求

为了得到稳定结果，采集数据需要满足以下条件。

标定板要稳定。采集过程中标定板不能移动，也不能明显弯曲、反光或被遮挡。

姿态要丰富。机器人需要从不同位置和不同角度观察标定板，尤其要有明显旋转变化。只在很小范围内移动，或所有图像角度几乎一样，会导致手眼约束不足。

相机内参要匹配。相机内参必须和采集图像的分辨率、对齐方式和实际相机一致。内参错误会直接影响标定板三维位姿估计。

标定板尺寸要真实。标定板上 marker 或格子的物理尺寸必须准确，单位要统一。尺寸错误会按比例影响平移结果。

机器人位姿和图像要对应同一时刻。机器人还在运动时采图，或者图像和机器人位姿不是同一个静止状态，会引入系统误差。

样本数量要足够。少量样本可能刚好满足计算，但无法抵抗噪声和局部误检。实际采集应保证有足够多的有效姿态。

## 9. 结果如何理解

手眼标定结果不是“某个点的位置”，而是两个坐标系之间的完整空间关系。它既包含方向，也包含位置。

固定相机外参的含义是：相机坐标系中的任意三维点，都可以通过这个变换转换到机器人基座坐标系。对于固定相机抓取，这个结果是最关键的。

腕部相机外参的含义是：相机相对于机器人末端的固定安装关系。它本身不是固定的机器人基座外参；只有结合机器人当前末端位姿，才能得到当前时刻腕部相机在机器人基座中的位姿。

因此，阅读标定结果时要明确三件事：

1. 这个矩阵连接的是哪两个坐标系。
2. 这个矩阵的方向是从哪个坐标系变到哪个坐标系。
3. 这个矩阵适用于固定相机，还是适用于随末端运动的腕部相机。

只要这三点混淆，后续机器人抓取、点云转换或目标定位都会出现方向或位置错误。
